之前的反转形态都是较强的反转信号，一旦它们出现（看涨吞没形态，启明星形态，刺穿形态等），就表明多方已经从空方手中夺过了大权，或空方已经从多方手中抢回了主动权（看跌吞没形态，黄昏星形态，乌云盖顶形态等）。

这里讨论更多反转形态，其中一部分形态通常但不总是构成反转信号，因此是较弱的反转信号。包括孕线形态、平头顶部形态、平头底部形态、捉腰带蜡烛线、向上跳空二只乌鸦、反击蜡烛线等。以及一些强烈的反转信号，三只乌鸦、三山形态、三川形态、圆形顶、圆顶底、塔形顶、塔形底等。

# 4.1 孕线形态
**后一根蜡烛线的实体较小，且被前一根相对较长的实体包含进去**。图6.1所示就是**孕线形态**。长的蜡烛线是“母”蜡烛线，短的则是“子”蜡烛线。**纺锤线**（具有小实体的蜡烛线）在某些形态中很有用处，星线和孕线就是这些形态的例子。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141947739.png)
孕线与吞没形态相比：
- 两根蜡烛线的顺序恰好颠倒过来。在吞没形态中，后面是一根长长的实体，它将前一个小实体覆盖进去了；而孕线形态中，前一个是非常长的实体，它将后一个小实体包容起来。
- 吞没形态中，两根蜡烛线的实体的颜色应当互不相同，而孕线中这一点不是必要条件。无论如何最终也会发现，**绝大多数情况下，孕线形态的两个实体的颜色也是不同的**。

与其他一些反转形态相比，比如锤子线、上吊线或吞没形态等，孕线构成的反转信号通常不如它们重要。当然有时，孕线也可能构成重大趋势变化的警告信号，尤其是在它处于市场顶部的情况下。

图6.3显示一类特别的孕线形态，**十字孕线形态**（有时也称为**呆滞形态**），指的是孕线形态中第二天是一根十字线，而不是一个小实体，因为十字孕线形态包含了一根强有力的十字蜡烛线，所以这类形态被视为**主要反转信号**。无论在一般的孕线形态还是十字孕线形态中，上下影响的大小通常是无关紧要的。

图.jpg

孕线形态揭示了市场在其前后健康状况的明显反差。在牛市行情中，孕线形态的前一个长白色实体表明，市场本来充满了活力，但是后一个小小的实体却反映出市场犹疑不定。这说明牛方上的推动力正在衰退。由此看来，有可能发生趋势反转。在熊市行情中，孕线形态的前一根长黑色蜡烛线反映了沉重的抛售压力，但随后的小实体则表明市场踌躇不定，第二天的小实体是个警告信号，说明熊方的力量正在衰弱。因此本形态可能构成趋势反转信号。

图6.4所示：
1. 4.18开始，有一段小规模的上涨行情。孕线1结束了这段行情。
2. 从孕线行情1开始，市场形成了一轮抛售行情，孕线2又阻止了这轮下跌过程。
3. 孕线3表示，即使在孕线出现前市场并无明显的跌势，孕线形态有可能具有一定的参考价值。注意，5月的前几天，市场并无明显的趋势可循。就在这时孕线3出现了，根据这个形态发出的信号，可以得出判断：由其第一天坚挺白色实体代表的上涨行情已经归于失败，此时市场处于上下两难的状态中。当市场收市于孕线3的高点以上时，才从这种犹疑状态解脱出来；**只有市场解脱出来后，我们才能做出买进的建议**。
4. 孕线4是一个经典实例，本形态高高的白色实体之前，市场呈现明显的上升趋势，当次日的小实体形成后，这个孕线形态就完成了。此外，这个小实体还具有另一方面的疲弱意义，这是一根流星线（虽然它不是一个完美的星线，因为它的实体不在前一个实体的上方）。

图.jpg

图.jpg

图6.9所示，在其中孕线形态出现后，市场从急剧的下降趋势转换为水平延伸的交易区间，这个孕线之前的下跌过程中，市场价格从5.4美元降低到4.85美元。我们看到孕线形态如中流砥柱，堵住了这场暴跌。但孕线的出现未必一定预示着市场的上涨。在孕线出现后，市场通常缓和下来，转换为横向整理区间。

# 4.2 十字孕线形态
常规孕线形态中，第一根为长实体，第二根为小实体，但多小才算小，这一点具有主观性。作为一条普遍经验：**孕线形态中，第二根实体越小，则整个形态越有力量**。因为第二根实体越小，市场的矛盾心理就越甚，越可能趋势反转。极端情况下，就形成了一根十字线。

十字孕线蕴含的技术意义，比普通的孕线形态重要得多，一般的孕线形态并不属于主要反转形态，但**十字孕线形态恰恰是一种主要反转形态**。一旦在一根很长的白蜡烛线之后出现了一根十字孕线，如果多头交易商对这个形态视而不见的话，它就把自己推到了危险的境地。十字孕线形态也可能引发底部过程，不过当这类形态出现在市场顶部时更有效力。

图6.10所示，3月中开始曾有一轮上涨行情，但4月2日和3日形成的十字孕线出现后，这个上升趋势就终止了。注意上述演变过程是如何发生的。

图6.11所示，1月中旬出现了一个巨大的向上价格跳空，似乎大喊“牛市”！但图中的孕线宣布，牛市到此结束。

图6.12中，由一根不同寻常的巨大黑色蜡烛线，与后面的一根十字线开始，组成了一个十字孕线形态。从中看到，从这个形态开始，市场从之前的下降趋势中挣脱出来。在这个十字孕线的十字线后面，还有一根外形与锤子线相像的蜡烛线（这根蜡烛线成功向下试探了市场最近形成的低点），这根蜡烛线给出了当前底部形态的进一步证据。

# 4.3 平头顶部形态和平头底部形态
平头形态由**具有几乎相同水平的最高点的两根蜡烛线**组成，或者由**具有几乎相同的最低点的两根蜡烛线**组成。之所以称为平头形态，是因为这些蜡烛线的端点就像镊子一样平齐。上升市场中，几根蜡烛线的最高点不相上下时，就形成了一个平头顶部形态。下降市场中，几根蜡烛线的最低点基本一致时，就形成了一个平头底部形态。

**平头形态即可由实体组成，也可由影线或十字线组成；即可由相邻蜡烛线组成，也可由相隔较近的蜡烛线组成**。不过这种情况下，它通常不能成为一个决定性的反转形态。构成平头形态的蜡烛线也可能相隔甚远，并且中间夹着较长期的市场变化；或者平头形态内，同时包含其他看跌的蜡烛图形态（在构成顶部反转信号时），或者同时包含其他看涨的蜡烛图形态（在构成底部反转信号时）。这样的情况下，平头形态就多了一些额外的技术分量。图6.13到6.18揭示上述概念。

图6.13中，上升趋势中，先是一根长白色蜡烛线，后是一根十字线，这个二蜡烛线既是一个十字孕线形态，也是一个平头形态，因为这两根蜡烛线具有同样的最高点。综合来看，这个形态可能构成了重要的反转信号。

图.jpg

图6.14中，这个平头形态中，先是一根长白色蜡烛线，后是一根上吊线，下一天，如果市场开市于上吊线的实体之下，那么把这个形态判断为一个顶部反转信号，就有了很大的胜算。只要市场的收市价不高于这个平头形态的顶部，那么这种看跌的态度就不可动摇。这个二蜡烛线的混合体也可以看做一个孕线形态。结合以上分析，这个孕线形态处于上升趋势中，构成了一个顶部反转形态。

图.jpg

图6.15中，这个平头顶部形态中，第二根蜡烛线同时又是一根看跌的流星线，尽管它不是一根真正的流星线，但根据形成一根蜡烛线的价格变化过程，这根线本身是看跌的，在这根蜡烛线上，市场开市于最低点，然后上冲到前一天的最高价的水平，后来却收市于当日的最低点附近。另外，本形态还可以看成孕线形态。

图.jpg

图6.16中，是一个乌云盖顶形态的变体，这个形态中，第二天的开市价高于第一天的收市价（而不是高于第一天的最高价）。黑色蜡烛线的最高点曾经触及前一天的最高点，而后市场再回落。这个形态即可看做乌云盖顶形态，也可看做平头顶部形态，是一个双重组合。

图.jpg

图6.17中，这里的二蜡烛线形态中，后一根为锤子线，并且它成功向下试探了前一根长黑色蜡烛线的最低点。锤子线、市场对支撑水平的成功试探，两方面因素同时证明卖方已经丧失了对市场的控制。最后这个二蜡烛线组合也可看做孕线形态。这是将此处判断为一个重要支撑水平的第三条理由。

图6.18中，为一个看涨刺穿形态的变体，它同时还构成了一个平头底部形态，二者形成了一个有力的组合。在理想的刺穿形态中，第二天的开市价低于第一天的最低点，但这个形态中，第二天的开市价仅低于第一天的收市价。

# 4.4 捉腰带线
捉腰带形态是由单独一根蜡烛线构成的，既可能具有看涨的意义，也可能具有看跌的意义。看涨捉腰带是一根坚挺的白色蜡烛线，其开市价位于当日的最低点（或者只有极短的下影线），然后市场一路上扬，又称为**开盘秃脚阳线**。如果市场处于低价区域，如图6.25出现了一根长长的看涨捉腰带线，则预示着上冲行情的到来。

看跌捉腰带形态，如图6.26，是一根长黑色蜡烛线，它开市于当日最高点（或者只有极短的上影线），然后市场一路下跌。在市场处于高价区的条件下，看跌捉腰带形态的出现，构成了顶部反转信号。也称为**开盘秃头阴线**。


捉腰带蜡烛线的长度越长。则该形态的技术意义重大，另外**如果捉腰带线是在市场趋势已经发展较长时间之后出现的。那么它的意义也更加重要**。如果市场收市于黑色的看跌捉腰带线之上，则意味着上升趋势已经恢复。如果市场收市于白色的看涨捉腰带线之下，则意味着市场的抛售压力重新积聚起来了。

图6.27：

2. 捉腰带线2很有意思。这条蜡烛线维持在前一周的低点之上，因此它不仅与前一周的地点一起构成了一个平头底部形态。同时也验证了这个平头形态的底部信号，随着该形态的完成，市场就开始上涨。
3. 直到数周后遇到一个孕线形态，这轮行情才结束。

# 4.5 向上跳空二只乌鸦
图6.30，为向上跳空二只乌鸦形态（拗口）。向上跳空是指图示的小黑色实体与它们之前的实体（即第一个小黑色实体之前的实体，通常是一根长长的白色实体）之间的价格跳空。图示形态中两个黑色小实体就是两只乌鸦。好像是矗立在高高树枝上的两只乌鸦，它们不详地向下凝视着。从这个形象的比喻来看，显而易见，这是一种看跌的价格形态。

在理想的向上跳空二只乌鸦形态中，**第二个黑色实体的开市价高于第一个黑色实体开市价，并且它的收市价低于第一个黑色实体的收市价**。
图.jpg

这个形态在技术上看跌的理论依据大致如下：
1. 市场本来处于上升趋势中，并且这一天的开市价从前一天的收市价相比是向上跳空的。但市场不能维持这个新高水平，结果当天反而形成一根黑色蜡烛线。到此为止，牛方至少还有几根救命稻草，因为这根黑色蜡烛线还能维持在前一天的收市价之上。
2. **第三天的行情则为市场抹上了更深的疲软色彩，当天市场曾经再度创出新高，但同样不能将这个新高水平维持到收市时**。而且更糟糕的是，第3日的收市价低于第2日收市价，如果市场果真如此坚挺，那为什么不能维持新高水平呢？为什么市场的收市价下降呢？这使牛方心中不安的盘算这些问题，结论往往也是，市场不如自己预期那样坚挺。
3. 如果次日也就是第4日，市场还是不能拿下前天的制高点，那么我们可以想见将会出现更低的价格。

还有一种与向上跳空二至乌鸦有点瓜葛的形态，其外形与其有一定的相似之处，但与向上跳空二只乌鸦形态不同的是，在上升行情中这个形态是看涨的。正因如此，它成了为数不多的蜡烛图持续形态中的一种，这种形态称为**铺垫形态**，铺垫形态发生在牛市行情中，是一种看涨的持续形态。在这个形态中，头三根蜡烛线与向上跳空二只乌鸦形态相似，但此后又跟了一根黑色蜡烛线。如果接下来的一根蜡烛线是白色的，并且向上跳空，向上超过了上述最后一根黑色蜡烛线的上影线，或者这根白色蜡烛线收市价高于最后一根黑色蜡烛线的最高价，则形成买入信号。在铺垫形态中，可以有两根，三根甚至四根黑色蜡烛线。

# 4.6 三只乌鸦
在向上跳空二只乌鸦形态中出现了两根黑色蜡烛线。如果在类似形态中连续出现三根依次下降的黑色蜡烛线，这构成了所谓的三只乌鸦形态。如图6.35所示，**如果三只乌鸦形态出现在高水平价格上，或者出现在经过了充分发展的上涨行情中，就预示着价格即将下跌**。有时三只乌鸦形态也称作三次乌鸦形态。好事不出门，坏事长翅膀（日本俗语）。

正如该形态的名称所示，三只乌鸦指的是这三根黑色蜡烛线。从形态上来说，**这三根黑色蜡烛线的收市价都应处于其最低点或接近最低点**，每根黑色蜡烛线的开市价都应该处于前一个实体的范围之内。另外分析者可能还希望三只乌鸦中第一根黑色蜡烛线实体处在之前那根白色蜡烛线的最高点以下。

# 4.7 反击线形态（约会线形态）
**当两根颜色相反的蜡烛线具有相同收市价时，就形成了一个反击线形态**，也称为约会线形态，描述这种形态最好方法就是讨论图6.38和图6.39形成的示意图。

图6.38，一个看涨反击蜡烛线的例子，本形态出现在下降行情中，在这个形态中，第一根蜡烛线是一根长黑色蜡烛线。在第二根蜡烛线上，市场开市价急剧向下跳空，到此为止，熊方觉得信心十足，但马上发动牛方反攻，将市场价格推了上来，使价格重新回到前一天收市价的水平。于是先前下降趋势就被勒住了。
图.jpg

不妨把看涨反击形态，同看涨刺穿形态做一番比较。刺穿形态同看涨反击线形态也是一样由两根蜡烛线组成，主要区别是**看涨反击线通常并不把收市价向上推进到前一天白色实体内，而是仅回升到前一天的收市价位置，刺穿形态中第二根蜡烛线深深向上穿刺到前一个黑色实体内**，因此刺穿形态比看涨反击线形态是一种更为重要的底部反转形态。尽管如此，正如下面所示的，看涨反击形态不容小觑。

从外形上看，看涨反击线形态，同看跌切入线形态（图4.31）也有相像之处，它们之间区别是**白色看涨反击线比切入线形态的白色蜡烛线更长**。换句话说，在看涨反击线上，市场开市时急剧向下跳空，然后市场再向上反弹，回升到前一天的收市水平。而在切入蜡烛线上，市场开市时稍稍下跌一些，然后便回升到前一天的收市水平。

图6.39，是一根看跌反击蜡烛线，这种形态属于顶部反转形态。当它出现时，将阻止之前的上涨行情，在这种反击线形态中，第一根蜡烛线是长白色蜡烛线，保持了牛市一贯的向上动力，下一根蜡烛线上，市场在开市时向上跳空，但从此时起熊方挺身而出发起反击，将价格拉回到前一天的收市价的水平。
图.jpg

如果说看涨反击线形态同刺穿形态有渊源的话，那么看跌反击线形态和乌云盖顶形态也有类似关系。看跌反击线形态中，第二天的开市价高于前一天的最高点。这一点与乌云盖顶形态是一致的，但与乌云盖顶形态不同的是，这一天的收市价并没有向下穿入到前一天的白色蜡烛线之内。由此看来，**乌云盖顶形态发出的顶部反转信号比看跌反击线形态更强**。

在反击线形态中，**一项重要的考虑因素是第二天的开市价是否强烈上升到较高的水平**（在看跌反击线形态中），**或者是否剧烈下降到较低的水平**（在看涨反击线形态中）。其核心思想是在该形态第二天开市时，市场本来已经顺着既有趋势向前迈进了一大步，但后来却发生意想不到的变故，到当日收市时，市场竟然完全返回到前一天收市价的水平。
