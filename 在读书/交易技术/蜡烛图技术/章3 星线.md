另一群反转形态，其共同点都是包含**星蜡烛线**（简称星线），如图5.1所示。

**星线的实体较小，且在它的实体与它前面较大的蜡烛线实体之间形成了价格跳空。只要星线的实体与前一个实体没有任何重叠，那这个星线就是成立的**。它的颜色不重要。星线既可能出现市场的顶部，也可能出现在市场的底部（下降趋势中的星线业称为雨滴）。如果星线的实体缩小为十字线，则称为十字星线，如图5.2所示。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512102146868.png)

星线，尤其十字星线出现时，是一个警告信号，表明当前趋势或许好景不长。星线较小的实体表示，多空双方已经转入僵持状态。
- 强劲的上升趋势中，牛方一直占据主导地位。如果在一根长长白色蜡烛线后出现一根星线，则构成警告信号：市场原先受买方控制，现在转为买方与卖方势均力敌的僵持状态。这既可能由于买方力量衰减，也可能由于卖方力量的增长而造成。无论哪个原因，都告诉我们：当前上升趋势的驱动力已经瓦解，市场容易受到卖方攻击而向下回落。
- 下降趋势中出现了星线，也是同样的道理。只是方向与之相反。

下列四种反转形态中，星线都是一项重要组成部分。这四种是：
1. 黄昏线形态；
2. 启明星形态；
3. 十字星形态；
4. 流星形态。

无论哪种星形态中，星线实体的颜色都无关紧要。
# 1. 启明星形态
## 1.1 概述
启明星形态属于底部反转形态，图5.3。这个形态预示价格的上涨。本形态中，先是一根长黑色实体，随后是一根小小的实体，并且两个实体之间形成一个向下跳空（**这两条蜡烛线组成基本的星线形态**）。第三天是一根白色实体，它明显向上推进到第一天的黑色实体之内。本形态发出的信号是，牛方已经重新夺回主导权。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512102155984.png)
为分析清楚本形态理论背景，将其三根蜡烛线逐一加以研究：
1. 当第一条黑色蜡烛线出现时，市场正处于下降趋势中，到此时为止，熊方占据上风。
2. 随后一天，是一个较小的实体。表示卖方已经失去了将市场进一步压低的能量。
3. 第三天，市场形成一根坚挺的白色实体，证明牛方已经夺取了统治权。

理想的启明星形态中，中间蜡烛线的实体，与它前后两个实体之间均有价格跳空，后面那个价格跳空较少见，但即使没有后面这个价格跳空，似乎也不会削减启明星形态的技术效力。
## 1.2 示例
图5.4，从12.19~21日，市场形成一个看涨的启明星形态。这个形态开始，市场酝酿了一轮上涨行情。但在遇上12.26~27的乌云盖顶形态后，就失去了上涨的动力。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512102157854.png)

图5.5，10月中的低点是市场以星线的形式创造出来的（10月头个星期的小实体）。这条星线的下一周，市场形成了一根强劲的白色实体，这条白色实体完成了图示的启明星形态。跟着这条白色蜡烛线的，是一条黑色蜡烛线，二者一起组成了一个乌云盖顶形态，随后市场暂时向下回落。尽管如此，该启明星形态还是构成了一个主要的底部。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512102210260.png)

图5.6，是一个启明星形态的变体，其中包含了好几条小星线（三颗星星），注意，第三根小实体（星线）既是一根锤子线，也是一根看涨的抱线。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512102306298.png)

# 2. 黄昏星形态
## 2.1 概述
黄昏星是启明星的顶部对等形态，是看跌的。由于是顶部反转形态，所以只有出现在上升趋势之后才能发挥其技术效力。

它由三根蜡烛线构成，如图5.7所示。前两根蜡烛线中，第一根是一根**长白色实体**，后一根是一根**星线**。星线的出现是顶部形态的第一个征兆。第三根蜡烛线具有**长黑色实体**，其强烈向下扎入第一天白色实体的内部，证实了顶部过程的发生，完成了这三线形态的黄昏星形态。

原则上说，黄昏星形态中，第一根和第二根实体间应有跳空，第二根与第三根实体间也形成另一个价格跳空。但根据经验，第二个价格跳空不常见，且对本形态的成功来说无关紧要，不是必要条件。**本形态关键之处在于第三天的黑色实体向下穿入第一天的白色实体的深浅程度**。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512102312379.png)
一些参考要素，如果黄昏星或启明星形态兼具这样的特征，则有助于增加它们构成反转信号的机会：
1. 如果在第一根蜡烛线实体，与星蜡烛线的实体之间，存在价格跳空；且在星线的实体，与第三根蜡烛线的实体之间，也存在价格跳空；
2. 如果第三根蜡烛线的收市价深深向下扎入第一根蜡烛线的实体内。
3. 如果第一根蜡烛线的交易量较轻，而第三根蜡烛线的交易量较重。这一点表明原有趋势力量的衰减，和新趋势力量的增长。
## 2.2 示例
图5.9黄昏星形态，出现在1987年夏的道琼斯指数，标志在当年那场暴跌之前的最高点。![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512102313796.png)

图5.10，9.5日最后一小时和次日头两个小时，构成黄昏星形态。其所结束的上涨行情，是从9月4日的启明星形态开始的。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512102313989.png)

虽然黄昏星形态在上升趋势后更为重要，但**如果它处在横向巩固区间的顶部，那么在其他看跌信号得到确认的条件下，也可能具有重要意义**。如图5.11，4月中旬出现的就是这种情况，这个形态中，**星线部分与一个阻挡区不约而同的重合**，阻挡区底部所处的水平为413$，这原本是3月份的支撑水平，这强化了本形态的疲弱意义。**过去的支撑常常转换为新的阻挡水平**，这一点要牢记于心！这是一条很有实用价值的交易规则。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512102316854.png)

图5.12，12月中旬出现了一个构造良好的黄昏星形态。星线前是一根坚挺白色实体，星线后是一根疲软的黑色实体；11月中旬，出现了一个黄昏星变体，这里说是变体，不仅是因为它的外观与黄昏星形态稍有相似之处，而且因为11月21日是一根上吊线（这就是这个黄昏星形态的“星”），**上吊线次日，市场开市于上吊线的实体下，确认了顶部形态的完成**。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512102320706.png)

# 3. 十字启明星和十字黄昏星形态
如果在上升趋势中出现了一根十字线，且这根十字线与前一个实体构成了向上的价格跳空；或下降趋势中出现了一根十字线，且与前一个实体构成了向下的价格跳空，那么这根十字线就称为**十字星蜡烛线**（十字星线）。如图5.2所示：

十字星线的出现，构成了**潜在的警告信号**，表明市场的当前趋势已经易于发生变化。这根十字线后的蜡烛线，应当构成**趋势反转的验证信号**。具体说来：
1. 在上升趋势中，如果十字星线后跟随一根长长的黑色实体，并且它的收市价深深向下扎入十字星线前的白色实体内部，那么，这根黑色实体就构成了市场顶部反转过程的验证信号。这种形态称为**十字黄昏星形态**。如图5.13所示。它包含的星线是一根十字线，所以具有更重要的技术意义。
   值得注意的是，如果十字星线后，是一根向上跳空的白色蜡烛线，那这根十字星线的疲弱意义就不再成立。
2. 在下降趋势中，如果一根黑色实体后，跟踪一根十字星线，又跟随一根长长的白色实体，并且它的收市价显著向上扎入第一根黑色实体内部，那么，这根白色实体就构成了市场底部反转过程的验证信号。这种形态称为**十字启明星形态**。如图5.14所示。
   值得注意的是，如果十字星线后，是一根向下跳空的黑色蜡烛线，那这根十字星线潜在的看涨意义就不再成立。
   这就是为什么在十字星线出现后，我们必须等待下面一、二个时间单位的验证信号的原因。
3. 在上升趋势中，如果市场出现一根向上跳空的十字星线（就是说，它的下影线与前一根蜡烛线的上影线没有任何重叠之处），它后面再跟踪一条向下跳空的黑色蜡烛线（这根线的上影线与十字星线的下影线之间也没有任何重叠之处），那这就构成了一个主要顶部反转信号，称为**弃婴顶部形态**，图5.15。这种形态非常罕见！
4. 在下降趋势中，如果一根十字星线的前后均发生价格跳空（包括有关蜡烛线的上下影线也互不接触），那这就构成了一个主要底部反转形态，称为**弃婴底部形态**，图5.16。这种形态也极为少见！

![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141814168.png)

图5.17，6月初有一条十字星线，它止住了先前的价格下跌，虽然它的影线与前一天的黑色实体有所重叠，但它依然满足星线的条件。这条星线后，出现一条白色实体，共同构成了一个三线形态的十字启明星形态。这就确认了下跌行情的结束。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141826822.png)

图5.18，十字星线上，价格曾经一度向下突破了0.85$的水平，**这是7月初形成的支撑区，但市场无力维持这里的新低价位**，这一事实本身就具有看涨的意义，再加上图示的十字启明星形态，就有两方面的理由推测这一市场底部。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141826533.png)

图5.19，既有一个十字黄昏星形态，也有一个普通的黄昏星形态。从1986.3到1986.5，市场价格变化构成一个十字黄昏星形态，本形态阻止了仅从一二个月前开始的剧烈上涨行情，随着这个十字黄昏星形态的出现，发生了一段抛售行情。后来，一个看涨吞没形态结束了这段下跌行情。1987年中，出现了一个黄昏星形态，成为从上述吞没形态开始的上升趋势的顶部。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141826272.png)

图5.20，3月17日，18日，19日构成一个十字黄昏星形态，结束了前一周的锤子线开始的上涨行情。本示例再次说明，股票市场上某些蜡烛图形态在外形上可能具有更大灵活性，这是因为股票和期货市场不同，股票市场的开市价大多可能与前一日的收市价基本相同。在我们分析特定某些蜡烛图形态时，本来要将当日开市价同前一日的收市价联系在一起，但从这一事实出发，**这样的条件就必须进行相应的调整**。本例中，这根十字黄昏星并不是一条真正的星线，根据定义，十字星线的实体（开市或收市价，二者相等）应当高于前一天的实体，但这里并非如此。当然，随着股票市场蜡烛图技术分析经验的增长，终究会发现到底哪些形态必须有所调整。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141827129.png)

图5.21，在距离1987年大股灾的几个星期前，市场构成了一个十字黄昏星顶部形态。这个形态中，中间的蜡烛线（即十字星线）与前一个白色蜡烛线的实体并没有形成向上跳空，真正的星线应当具有这样的跳空。但无论如何，股票市场在价格跳空的问题上，应当允许更大的自由度。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141827636.png)

图5.22，显露了一个极不寻常的、兆头险恶的现象，这里肩并肩接连出现两个十字黄昏星形态。

# 4. 流星形态
流星形态是一种二蜡烛线形态，外观就像一颗流星。它发出警告信号，表明市场顶部就在眼前。**它的技术意义不如黄昏星形态强，通常不构成主要反转信号**。

图5.23，流星形态中，**流星线具有较小的实体，且实体处于其价格区间的下端。同时流星线的上影线较长**。同所有星蜡烛线一样，**流星线实体的颜色并不重要**。流星线的形状形象地显示，当日市场开始于它的最低点附近，后来剧烈上冲，但最后却向下回落，收市于开市价附近。即**这个交易时间内的上冲行情不能够维持下去**。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141844233.png)
理想的流星形态中，**流星线的实体与前一根蜡烛线实体间存在价格跳空**，不过这不是非有不可的。图5.24中，4月2日形成一个看跌的流星形态，标志当前上升趋势前途不妙。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141847586.png)

流星形态的变体包括下列情形，如图5.25所示：
1. 流星形态1，实际属于流星形态变体，其中的流星线不是一个理想的星线，因为在有关的实体之间没有价格跳空，但从结果看这个形态证明牛方无力维持价格上涨的势头。
2. 流星形态2没有多大意义，这个形态确实符合流星线的一部分要求（较小的实体与较长的上影线），然而还有一条重要判别准则它未能满足，因为本形态既没有出现在上升趋势后，也不是处于横向巩固区间的顶部。如此就只能将它看作具有较小实体的、意义寻常的一根普通蜡烛线。
3. 流星形态3具有流星形态的外形，却不构成真正的星形态，因为它的实体没有从前一个实体向上跳空。但应当把这一天的流星线放到它所处的市场大环境中考察。流星线3的上影线的顶部，市场曾对8月上旬的高点6.18$的水平，发起过挑战。不过在这场交易日内的上涨行情中，牛方在尝试上述阻挡水平时精疲力竭。最后，图示大豆市场竟以接近当日最低价的水平收市。
4. 流星形态4与流星形态3极其相似，它不是一个理想的流星形态，但这根流星线上，市场再次向上挑战了6.18$的阻挡水平，但还是功亏一篑。由此证明，牛方无力夺回主动权。
5. 流星形态5又是市场向上试探阻挡水平失败的一个例子。不过行情发展到这种地步，不得不对牛方企图向上推动市场的坚韧意志怀有几分敬意。随着牛方在6.18$阻挡水平的又一次碰壁，不禁要猜测，他们到底还要坚持多久才肯最终放弃呢？
6. 流星形态6是市场最后一次失败的向上尝试。随后牛方放弃顽抗，市场开始下跌。
7. 最后，一根锤子线结束了这段抛售行情。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141848550.png)
> 在研究蜡烛图线和形态时，价格形态不一定要十全十美才能发出有效交易信号，总是应当结合其他各方面的技术线索进行综合判断，具体情况具体分析。

图5.26，流星形态的实力与上述情况类似。这个流星形态中，流星实体没有从前一个实体向上跳空，经过如此，它也构成了重要的反转信号。历史背景是，本形态处，市场对1989年第3季度的历史高点水平再次作了向上试探，但还是无功而返。于是，这个形态标志从图示开始的锤子线开始的上涨行情的终结。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141908657.png)

图5.27为一个经典的流星形态，它出现在5月29日的第一个小时，从此开始下跌，直到6月4日出现了一个看涨吞没形态，这轮行情才告完成。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141909179.png)

图5.28，显示了2个流星形态，在它们身后，均出现了明显的价格下跌过程。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141909462.png)

# 5. 倒锤子形态
虽然倒锤子线不属于星线形态，但由于它的外形与流星线相似，所以也讨论下。

图5.31，倒锤子线看上去和流星线相似，它也具有较长的上影线，较小的实体，并且这个实体居于整个价格范围的下端。但不同的是，**流星线是一根顶部反转蜡烛线，而倒锤子线却是一根底部反转蜡烛线**。如果倒锤子线出现在下降趋势后，则构成一个看涨的蜡烛图形态。这一点与普通的锤子线如出一辙。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141920857.png)

图5.27中，6月4日的看涨吞没形态的第一根蜡烛线，外形与流星线相同（这种蜡烛线实体的颜色无所谓），在这个示例中，这根蜡烛线处于下降趋势中，因此成为一个潜在的看涨倒锤子线。

在分析倒锤子线时，一点非常重要：当倒锤子线出现后，必须等待下一个时间单位的看涨信号对它加以验证。倒锤子线的验证信号可能采取下面这样的形式：**倒锤子线次日的开市价向上跳空，超过倒锤子线的实体，向上跳空的距离越大，验证信号越强烈**。还可能采取另一种形式：**倒锤子线次日是一根白色蜡烛线**，并且它的价格均处于较高的水平。

对于倒锤子线形态，之所以看涨验证信号非常重要，是因为**形成倒锤子线的价格变化过程看起来似乎是看跌的**，即当日市场的开市价位于当日最低价处或接近最低价，后来市场上涨了，但牛方无力将上涨行情维持下去，最后市场收市于当日最低价或最低价附近。

**为什么这样的蜡烛线竟然是潜在的看涨反转信号呢？其解答必须从下一天的行情中寻找**。如果下一日市场开市于倒锤子线的实体之上，则意味着凡是在倒锤子线当日开始和收市时卖出做空的人现在统统处于亏损状态。**市场维持在倒锤子线实体之上的时间越久，则上述空头止损出市的可能越大**。这种情况下，首先可能引发空头平仓上涨行情，然后空头平仓上涨行情可能促使企图抄底做多的人跟风买入，这个过程自我循环，市场螺旋上升，最后就可能形成一段上升趋势。

图5.32所示：
1. 流星线1让市场放松下来，从先前剧烈上冲转为实质上的水平交易区间。
2. 流星线3之后，出现一根黑色蜡烛线，一方面完成了**一个看跌吞没形态**，另一方面也验证了**流星线的顶部反转形态**。
3. 3月27日和28日组成了一个刺穿形态，它结束了从流星形态3开始的下跌过程。以这个形态为基础，市场开始上涨。
4. 这段上涨行情终止于流星线4。
5. 流星线4后面的下降趋势，终止于4月21日的倒锤子线，它的次日是一根较高的白色实体，由此确认了这根倒锤子线的信号。**倘若这根白色实体再长一些，那我们就可以说这里出现了一个看涨的启明星形态**（倒锤子线之前的黑色实体、倒锤子线本身、倒锤子线之后的这根白色实体，将组成一个三蜡烛线的启明星形态）。由这条看涨的倒锤子线引发的上冲行情，推动了价格的上涨。
6. 直到另一个流星形态5出现，这段上升趋势才结束。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202512141910750.png)

图5.33中，倒锤子线1和2为它们次日坚挺的价格变化所验证。再强调一次，**倒锤子线必须得到进一步的验证，这一点非常重要**！倒锤子线2也是图示启明星形态的一个组成部分。
