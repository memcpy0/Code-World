图表形态识别技术常带有主观色彩，不过摆动指数是经过数学运算得出的一种技术工具。用它分析市场能得出更客观的结论。他们也构成了许多计算机交易系统的基础。

所以摆动指数包括下列各种技术分析工具。相对力度指数，随机指数，动力指数等。

摆动指数能从如如下三个方面为者提供帮助。
一一，摆动指数可以用作相互验证，相互背离指标，这就是说当价格变动方向与摆动指数变动方向不一致时，就构成了一个相互背离信号。摆动指数能够发出警告信号，说明当前价格趋势也许即将陷入停顿，百度指数和甲鱼两种相互背离的情况。一是互相相互背离，或者说看跌向后背，你当价格创出新高时，相应的摆动指数却没有达到新高。这一股的市场在本质上是疲弱的，另外一种是正面相互背离，或者说看到相互背离。是指将价格处于新低时，相应的摆动指数却没有新的新低，这意味着当前市场的抛售压力正在衰退。
二，百度指数也可以用作超买超卖指标。百度指数能告诉交易者当前市场行情是不是向某一方向伸展的太过分了，因而容易引起调整行情。不过当我们采用摆动指数来作为超买超卖指标时，必须谨慎从事。因为摆动指数在构造方法上的原因，它们主要适用于水平延伸的市场环境，在某个新的主要趋势刚开头时，如果我们只靠摆动指数来作为超买超卖指标，这可能引出问题。举例来说，如果市场向上突破一个水平调整的区间，这意味着新的牛市阶段的开端，但与此同时，摆动指数可能总是维持在超买状态下。
三，摆动指数还能用来衡量市场运动的力度，因此可以利用它们较严一一轮趋势性运动背后市场力量的大小，例如动力指数通过对价格变化幅度的比较显示了价格运动的速度，从理论上来说，随着趋势的发展，价格变化速度也应当逐步加快。如果在趋势发展过程中，动力指数变成水平伸展，可能构成了一个早期的警告信号，说明当前价格运动正在减速。
在顺应当前主流趋势方向的条件下，我们可以采用摆动指数信号来建立头寸。于是当看涨的摆动指数信号出现时，如果当前主要趋势是上升的，则应当买进做多，如果当前主要趋势是下降的，则应当平回空头寸。对于相反的摆动指数信号，我们应当采取上述相同的应对方法，只是方向相反。绝不可仅因为出现一个看跌的摆动指数信号就卖出做空，除非当前的主流趋势方向向下，如果没有这样的先决条件，那么我们只能利用这个看跌的摆动指数信号来促进多头头寸。

相对密度指数
在期货交易商中，相对密度指数ri是最流行的技术工具之一。Time他比较了一段时间内价格的上涨与下跌之间的相对密度，在ri研究中，9天和14天是最常用的两种时间参数。
如何计算ri？
Ri的计算方法是首先分别累加出一定时间之内上涨的价格幅度适合与下跌的价格幅度之和，然后再求得两者的比值，在计算过程中一般仅采用收视架作为价格数据，它的计算公式是？
$$RSI = 100 - \dfrac { 100 } { 1+ RS}$$
其中rs等于该时期上涨价格幅度的平均值除以该时期内下跌价格幅度的平均值

因此当我们计算14天的rsa时，首先将这14天内上涨了的收市价的上涨幅度相加。按照收市价对收市价的方式，再将所得的和除以14。然后对其中下一届的日子做同样计算，从这两个数值就得到了相对密度的值，最后我们把rs的值带入到si的公式中去。Ri公式将rss转化为指数形式，并使得该指数的取值范围在0~100之间。

如何运用ri？
Rsa的两个主要用途是构成超买超卖指标作为监测相互背离现象的工具。

他作为超买超卖指标的使用方法是当rsa向上趋紧其取值范围的上边界时，即让它高于70或80时。表明市场处于超买状态，在这样的情况下，市场也许变得比较脆弱，容易引发向上回落的过程，或者即将转入横向调整阶段。与此相反，当rsi除以其取值范围的下边界时，通常低于30或20，则认为它反映了超卖状态，在这样的环境下，市场有可能形成空头买入平仓行情。

用ra是相互背离现象的具体方法是，当价格向上创出当前趋势的新高，时而si却没有形成新高，不能与之配合，这就构成了一个负面向后背离信号，可能是一个看跌信号。当价格向下低出当前趋势新低时，si却没有形成新低，这构成了正面的相互背离现象。在相互背离现象出现时，如果si摆动指数的数值正处在超买区或超卖区，则相互背离现象具有更强的技术意义。

随机指数
对期货市场的技术分析者来说，随机摆动之处也是一种常用工具，作为一种摆动指数，它既提供了超买和超卖状态的毒素指示，也能揭示相互背离现象。还提供了一套比较短期趋势和长期趋势的机制随机指数，把最近的收视价格同一定时间范围内市场的总价格范围进行比较。随机是说数值出来0~100之间，当随机指数较高时，意为当前的收视价格在一定时期的整个价格中。接近上涨水平，但随机指数较低时，因为当前的收市价格在一定时期的整个价格范围内处于低端水平。随机指数的设计思想是当市场向上运动时，收市价倾向于接近上述价格区间的高点，当市场向下运动时，价格往往集中在上述价格区间的低点附近。

如何计算随机指数
？随机指数图表有两个曲线组成，它们分别是%K线和%D线。
其中 %K称为原始随机线/快%K线，这条曲线最为灵敏。%K线的计算公式是：
$$ \dfrac { 收市价 - N天内的最低价 } { N天内的最高价 - N天内的最低价 } \times 100 = \%K$$
其中，收市价 = 当前收市价；$N$ 天内的最低价 = $N$ 天内总的价格范围的最低价；$N$ 天内的最高价 = $N$ 天内总的价格范围的最高价。

公式中数字100，将公式的数值转为一个百分数值。因此如果今天收拾假与所研究的时间范围内最高价一致，那%K值就等于100。上述的时间范围既可以选择为若干天，也可以选择为若干星期，甚至可以选择为若干个日内时间单位，比如若干小时。9，14，21个时间单位是较为常用的时间指数。

因为快%K线十分起伏不定，所以通常我们以这根线为基础。每三个数值计算出一个移动平均值，得出一条较为平滑的三时间单位移动平均线，称为慢%K线。绝大多数技术分析使用这条慢%K线代替那条变换无常的快%K线。下一步对这条慢线再进行一次三时间单位的移动平均。得到慢%K线的三单位移动平均线，称为%D线，事实上这条%D线是移动平均线的移动平均线，如果想要弄清楚上述%K线和%D线之间的区别，那么我们不妨把他们设想为一个双移动平均线组合。其中慢%K线相当于一条较短期的移动平均线，而%D线相当于一条较长期的移动平均线。

如何应用随机指数

前面曾说过，我们可按照几种不同方式来使用它。最为常见的用法是用来揭示相互背离现象。绝大多数技术分析石材应用随机数使即从相互背离这一方面跟踪随机指数变化，也注意其数值是否显示市场超买超卖状态。

有些分析师还采用另一种研读方法，这种方法约定：当慢%K线向下穿过%D线时构成卖出信号，当慢%K线向上穿过%D线时构成买入信号，这点与双移动平均线的用法有相似之处。在双移动平均线系统中，较快的移动平均线向上穿越或向下穿越较慢的移动平均线时，就构成了买入信号或卖出信号。具体来说，为构成一个买入信号，需满足以下三个条件，首先，市场必须处于超卖状态。随机指数的地址为25%或更低，其次，市场已经发生了正面相互背离现象，最后慢%K线向上穿越%D线。

动力指数
动力指数又称价格如此说他栋梁的是当前的收视价格与一定天数之前的收视价格之差。如果我们研究10日动力指数，那么我们比较的就是今天的收市价和10日之前的收市价，如果今天的收市价高于10天之前的收市价，那么在动力指数轴上，今天的动力指数数值就是一个正值。如果10天的今天的收市价低于时间之前的收市价，那么今天的动力指数值就是负值。从东一直睡觉来看，在上升趋势的发展过程中，上述价格差即今天的收视角与我们选择了天枢之前的收视价之差，应当以逐步加快的速度增长，这样的情况显示该上升趋势就逐步上涨的驱动力。换句话说，价格变化的速度也是加快，如果价格上涨，而动力指数转为持平。就说明价格趋势处于减速状态，这可能构成一个早期高信号说明当前价格趋势可能会结束。如果动力指出向下穿过零线，这构成一个看跌信号，而当它向上穿过零线，这是一个看涨信号。

动力指数是一种现成的超买超卖指标均来说，当动力指数为一个相对较大的正值时，市场可能就处在超买状态，容易发生回落行情。动力指数通常在价格达到顶峰之前预先达到顶点，根据这一特点的动力指数处于极为超买的读数状况时，可能预示着一个价格高峰的行程。
