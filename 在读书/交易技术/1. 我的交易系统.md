**如果你的脑子「看不见」的话，你的眼睛也是看不见的**。这就意味著**我们的观察系统，实际上是一个思考系统**，也就是说，**我们如何去思考，哪一些特征是属于我们需要观察的部分**。

市场上太多信息，并不是所有的信息都需要去观察，那么这时，所谓的**观察系统也就是一个取舍系统**，有舍有得。应该来说，能为我们所用的一些最真实的数据，才是我们最需要去观察的数据。

哪一些数据最真实、最可靠、最直接、最及时？就是**价格**和**成交量**（**额**）这两样东西，而这两样东西，由于时间的变化也会产生空间上的变化，这就形成了趋势。

其实，**绝大多数人，赚的都是趋势的钱**。

一个最典型的K线图里体现了什么东西呢？我们能看到的，无非就是上下跳动的价格，以及它的时间长度，比如说从2000年开始一直到现在十几年的变动，这是一个时间的问题；从空间上来看，从24块多涨到了287块多，这是一个空间的问题。综合起来就是**价量时空**。

在世界上任何一个角落，任何一个软件，你打开这张图，它都一模一样。

价量时空这4大要素，是最直接，最真实，最实时，每一秒，每一毫秒，都呈现在你面前的，是我们极其要关注的东西。
# 1. 趋势的发展，斜率的变化
我们都说一波趋势，其变化经过**转折-开始-发展-极端-转折**五个阶段。那么怎么来看这个东西？还是回到刚才这张图，波音公司，周期类的股票，它这种波动，能够比较有趣一点。

比如说这一波趋势下来，会经历什么呢？
1. 首先是它从上升趋势进行一个转折，这里要有一个转折
2. 然后就进入到一个开始阶段
3. 然后再逐渐去发展它
4. 最后发展到一种极端的状态
5. 完了以后又会出现一个戏剧性的转折

那么看懂了这个问题以后，我们会发现，**另外一个有趣的现象**，那就是**斜率在变化**。开始阶段是比较缓的，发展阶段才是它真实的斜率，到极端后这个斜率会突然加大，完了以后出现戏剧性的转折。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202601270029584.png)
这是非常有趣的一件事情，那么这种斜率的变化，我们把它称之为**趋势强度的变化**。

图形分析它不是在做预测，它告诉你，已经发生了什么。这很重要，我们立足现实，已经有这些数据，或者说，**我们立足于客观、去展望未来，但是你不要去预判，我们不去猜、不去赌这种概率性事件**。

那么斜率变化你要按照这种画浪形的做法去做的话，千人千浪，没有人能知道到底是怎么回事，而我把这些事情，所有的波浪，我把它缩减为一个词，就是**斜率**。

这个斜率还可以有其他多种表达的方式，比如说可以用箭头的方式去表达，其实你眼睛看，你只需要用裸眼看，你就能看得出来某些变化，是吧，这些斜率。我们说**趋势的强度**，实际上就是**它的斜度的变化**，但我们不能简单地说斜度就是这样：
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202601282030071.png)
当然不是这样，它的斜度很明显是这样子的，对不对，**它是一个弧形的斜度**，我们不能用一根直线来替代，这是不科学的。

于是就需要引入另外一个概念，我们常用的叫做**移动平均线**的一个概念。上面我们画的直线是趋势线的概念。**趋势线也是千人千线**，比如说像刚才这一波上来，有的人认为它是一个斜率，但我认为它不是一个斜率，**它有多个斜率**。

很多人认为**跌破趋势线怎么样，涨破趋势线又怎么样，都不科学**，所以这时，我们就可以引入一条均线，比如说，我们以一个中期均线，60日均线来看，你可以发现到这根均线就已经实现了，我刚才想要表达的意思：这根线，不是一根直线，它是一根曲线。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202601282037771.png)
# 2. 移动平均线与「抵扣价原理」
事实上，**趋势的强度，它不是直线发展，它需要有一种斜率的变化**，这种斜率的变化，你也不能简单的说，用几根线咔咔表现出来。它有可能就是一种很缓和的曲线的变化，那么这种斜率如何来表达？这个时候就要用到均线。

那么**我们研究市场价格平均线，实际上就是在研究市场成本和其中的一些人性问题**，所以这里先来讨论另外一个问题——市场平均成本是怎么算出来的？

我们看一下，市场5天的平均成本，就是从今天开始倒推5天的收盘价之和除以5，就得出了今天的5日均线，那么有趣的一件事情出现了，我想知道，明天的MA5是什么？

当然，明天的MA5，也就是(明天的收盘价+今天的收盘价+昨天+前天+大前天)/5，就得到了明天的收盘价。

今天的MA5：
$$\text{MA5}_{Today}= \dfrac{ \text{Close}_{today} + \text{Close}_{today-1} + \text{Close}_{today-2} + \text{Close}_{today-3} + \text{Close}_{today-4}} {5}$$
明天的MA5：
$$\text{MA5}_{Tomorrow}= \dfrac{ \text{Close}_{Tomorrow} + \text{Close}_{today} + \text{Close}_{today-1} + \text{Close}_{today-2} + \text{Close}_{today-3}} {5}$$
如果希望明天的MA5>今天的MA5，则需要：
$$ \text{Close}_{Tomorrow} >  \text{Close}_{Today -4}$$
这种现象就叫做MA均线的**抵扣现象**。我想知道：
- 今天收盘以后的MA5是不是大于昨天的，其实很简单，只需要今天的收盘价，大于5天前的收盘价就可以了；
- 明天收盘以后的MA5是否大于今天，也很简单，只需要明天的收盘价大于4天前的收盘价。
# 3. 趋势的本质
换句话说，趋势的本质是什么？**市场趋势的本质就是市场成本的运动，就是均线运动的结果**，**市场趋势的方向，就是均线运动的方向**。
> 市场成本决定价格，市场价格围绕市场成本上下波动。

所以我们如果要判断一个趋势是不是能往上，我们只需要找出一根成本线，我希望这个成本线一直往上走，那么这就是一个向上的趋势。如果一个向下的趋势，什么时候能逆转成向上的趋势，很简单，只需要找到某一根均线，它能够拐头向上，这根均线能维持一直向上的一个动作，那么这个趋势就已经发生逆转了。

我们通过刚刚提到的抵扣价原理，计算均线到底会不会往上走，会不会朝著我们想要的方向走，先搞懂这个，后面的很多事情就迎刃而解。

前一段时间GE跌的很厉害，现在从图形上看有没有机会抄底，首先要做的一件事情，就是判断**20天均线能不能往上拐头**？大概看一下，未来2~3周，GE的20天抵扣价将会在这个范围里波动：
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202601282053672.png)
也就是说，只要接下去的10天左右时间在这个范围内波动，这个范围内的最高收盘价是在这个地方，我把这个盒子移过来，也就是说在未来一段时间内，股价能站上这根紫颜色的横线，20天均线就要开始拐头，这个应该是很好理解的。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202601270050838.png)
所以你完全可以在这个地方**设置一个买入价格提醒**，如果说有哪一天出现往上走，就站上了20天均线，同时由于它站上这根均线，并且不往下跌回来的话，20天均线将逐渐往上拐头。

用抵扣价原理来判断均线是否拐头这件事情，一定要动态来看，你要想象一下，当前的20天抵扣价在这，它接下去是怎么运动，当前的收盘价怎么样运动，才能让它这样上去，这就是**可预知的趋势当中最重要的一个环节**，就是**要利用抵扣价来对成本均线进行预演**。这是非常重要的概念。

当你会用这个东西了以后，我们还可以用另外一组均线来看，它是不是真能把这个趋势稳定住，真正往上走，EMA均线就是这个曲线。
# 4. 双均线验证趋势可靠性
**EMA均线，它是你能站上它，它就往上走**。

我们刚才说在紫颜色线之上，那么这个MA均线就开始往上走，但紫颜色之上是不是也能站上EMA均线呢，如果也能站上，那么这两根均线同时往上走，也就是说我们有一个预判，有一个确认，那这个趋势大概率就已经成型了。

当然了，什么时候能让60天均线往上走，让120天均线往上走。20天往上了以后，接下去一个任务，就是要把60天也要往上带，最后把120天往上带，一旦这三根均线都形成了往上走的趋势，这个趋势就是一个大趋势，逐渐地走出来。

我的系统里面用EMA均线（预判趋势变化的有效性），来验证这个拐头是否有效。这是两个不同的概念。
# 5. 均线密集与乖离率
还有一个非常重要的概念，就是**均线密集**，本质上是**市场各个时期的交易者的成本趋于一致**。

一般来说，我们说均线是什么，均线实际上就是多少个价格加起来，用一种数学方式得出来一个一个值。我们也可以把它理解为市场成本。

**当均线密集以后，往往是一波大行情的开始**，所谓均线密集大行情，像这个是属于是周线图，**周线图上面的均线密集，至少是一个翻倍行情**。这里也是一个均线，从71涨到了150，然后再从130-140涨到200，这种大行情你是一定要抓住的。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202601270136416.png)
另一种情况，**远远偏离长期均线**，有时候上涨也是过于偏离长期的价格平均线。就好比我持有一个股票，它已经远远涨的超过预期，这个时候就有卖出需求，这样的人做的事情多了以后，股价就会逐渐回归。所以这时又需要另外一个指标进行参考，就是**乖离率**——**股价偏离长期均线的距离**，如DIFF(120)。

我们可以看一下，当它跌到这个程度时，这里是多少呢？最低的收盘价不是最低价，离120天的EMA这根线，相差了多少呢，相差了50%，也就是说，它偏离市场长期平均成本有50%之多。
![](https://image-1307616428.cos.ap-beijing.myqcloud.com/Obsidian/202601270143395.png)
大幅杀跌或大幅上涨，这种极端行情，很有可能迅速转折，因为它必须要回归，像这个也是偏离度相当大，达到了50%以上，偏离长期均线50%以上。也有可能要回来，什么时候回归不知道。
# 6. 必由之路
我们提到的一个概念说，**趋势的本质是市场成本的变化**，那么**成本均线**，我们说的移动平均线，实际上**就是在告诉我们成本是怎样变化**，然后我们根据这些成本变化，和对斜率的理解，以及对市场人性、对发展方向的一个判断，我们可以做出预演。

请注意，**这不是预测，是预演**，我预演它什么时候均线会发生改变，实质上也就是说，什么时候趋势的斜率会发生改变。均线的拐头，就意味著斜率发生了变化。

可预知的趋势，并不是去预测，去猜，而是我们用合理的方法，去算出来，去推理出来，均线何时发生拐头或者说是斜率变化。这是非常重要的。

如果说，我们能从这一系列的推演过程当中，得知趋势即将发生变化时，我们就在必由之路上做好准备就可以了，**不猜不赌，在必由之路上就等著它**。你要往上走，你必须经过这个位置。你要往下跌，你也必须经过某一个关键位置。这个位置是可以通过我们之前的一系列方法，可以推算出来。我就在那等著，你什么时候来，我就做好准备。

所以说，我经常说，2B只能解决一个什么问题，**2B只能解决一个过度偏离以后的回归问题**。完了以后**真正的大行情，往往在均线密集之后**。那么我们通过这样的预演，你就可以知道哪些是关键位置，需要等到某一个关键位置去动手。

这就是必由之路，你只需要在均线密集时，在这个位置设置一个买入价格触发，它要往上走，它必须要经过这个位置，这个位置就是一个必由之路。那么我们**通过抵扣价来推演均线的运动方向**，实际上就是在推演市场成本的运动方向，市场成本的运动方向就是市场趋势的运动方向。

这个概念是这一条线路下来，我们所有做的这一切不是在预测，而是通过合理的算法去预演它，去验证它。之后得出非常重要的一些战略位置，在某些战略位置上等著他，因为它要往上走或是往下跌，它都必须经过这条路，这就叫做**必由之路**。

**我们在必由之路上等著它，你一定会有收获**。
# 7. 怎样看待成交量（额）
讲完了价以后说量，我的观点当中认为**成交量就是市场分歧**。

也就是说在某一天，不管价格是涨是跌，**如果出现非常大的成交量**，我们基本上可以认定：**这一天的市场分歧非常大**，这是多空双方的一个较力的过程。**没有分歧的行情，不会有什么成交量**。

成交量的另外一部分，我认为更有趣的应该是成交额。成交量和成交额，本质上说是不一样，**成交量只是说有多少个交换，而成交额是实实在在的金额**。

比如说我们看一下，这是推特，那么在已经从起始位置开始，已经涨了百分之30多，突然爆这么大的量，也就是说这个价格，市场上有分歧，分歧越大，未来的行情的确定性就越强。

你看这分歧多大，跳上跳下，那么现在的收盘价，当前的收盘价已经把过去这么长时间，过去差不多一年多时间里所有的分歧，所有在爆大量的这些日子里面敢于大胆买入的人，目前都是盈利的。那么我们且相信，推特这波行情恐怕是要往上走。

成交量这件事情，成交量和成交额这件事情，我们主要还是关注它的突变，我们要关注极端化，也就是说，突然一下特别大，你就要特别关心，小不用关心，**因为小就是没有分歧**。

大家都不愿意换手，不愿意买卖，交易清淡。所以交易清淡的行情，可以走很久很久，放量暴涨的暴跌的，都不得长久。是吧，大家搞清楚，因为分歧的问题。

# 10. 金融市场是人性放大器
我们所谓的图形，实际上说白了就是人性的一种体现

也有一种说法就是说，金融市场是一种人性的放大器，它把人性之善和之恶，都能够体现出来。

而且更容易把人性之恶放大，你的贪婪恐惧，对某些事情的漠视，你的那种短视、急功近利的心态，都会在金融市场被无限放大。

金融市场是一个波动的市场，**价格围绕市场成本上下波动**，那么在金融市场，每一个人在进行买卖交易的过程当中，他都是一种叫做称之为叫**本方有利原则**，每个人的买卖，都是认为这个事情是对我是有利的，这叫本方有利。不论是卖方还是买方，他都是站在本方有利的原则下进行的。

所以说，金融市场也是一个相对公平的市场，因为每个人都在考虑自己的利益，**当大家的利益发生冲突时就会有买卖**，我认为卖出对我有利，你认为买入对你有利，于是**就会有换手**，当然这是这是一个方面。

另外一个方面，他还会形成一种**羊群效应**，你买了赚钱了，他买也赚钱，你看菜场大妈都在买股票挣钱时，你也进去了，羊群效应就把你的贪婪，人性当中贪婪的部分给放大。

索罗斯写过一本叫做《金融炼金术》这本书也是值得大家多看，很难看懂，我看了这么多年了，还是不能够完全理解，它是一本哲学书。那么索罗斯提出的一个叫做反身性，他认为市场是非理性的，正是由于市场信息，每个人获取信息的渠道和信息本身的不完整性，他认为市场上不可能有真实的信息。

这就是说，我很重视图形，是因为我认为市场上没有完全真实的信息，这信息都是通过加工，变化，甚至同样的信息，在你脑海里和在我脑海里，反映出来的情况是不一样。

所以说信息本身的不完备性，和参与者自身的思考上的不完备性，性格上的不完备性，就会导致市场产生非理性，非理性最终只会朝只会朝著两个方向发展，也就是要么是泡沫，要么是崩溃。

这是他的市场的两个极端，那么这两个极端，也把它称之为叫人性的极端。你必须要掌握的原则，**人性之极才是你做投资做交易的最佳机会，除此之外的绝大多数时间不适合做交易**。

人性之极到了恐慌之极时，你不能恐慌。你要思考，**此时此刻处在市场的哪一个阶段**，是不是出现了人性之极，我们是不是有买入机会？当市场疯狂，全市场疯狂的时候，你在你要客观中立的看这个问题，说此时市场我还应该去买入吗？
