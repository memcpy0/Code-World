给你两个整数 `M` 和 `K`，和一个整数数组 `nums`。

一个整数序列 `seq` 如果满足以下条件，被称为 **魔法** 序列：
- `seq` 的序列长度为 `M`。
- `0 <= seq[i] < nums.length`
- $2^{seq[0]} + 2^{seq[1]} + \dots + 2^{seq[M - 1]}$ 的 **二进制形式** 有 `K` 个 **置位**。

这个序列的 **数组乘积** 定义为 `prod(seq) = (nums[seq[0]] * nums[seq[1]] * ... * nums[seq[M - 1]])`。

返回所有有效 **魔法** 序列的 **数组乘积** 的 **总和** 。

由于答案可能很大，返回结果对 `10^9 + 7` **取模**。

**置位** 是指一个数字的二进制表示中值为 1 的位。

**示例 1:**
```c
输入: M = 5, K = 5, nums = [1,10,100,10000,1000000]
输出: 991600007
解释:
所有 [0, 1, 2, 3, 4] 的排列都是魔法序列，每个序列的数组乘积是 10^13。
```
**示例 2:**
```c
输入: M = 2, K = 2, nums = [5,4,3,2,1]
输出: 170
解释:
魔法序列有 [0, 1]，[0, 2]，[0, 3]，[0, 4]，[1, 0]，[1, 2]，[1, 3]，[1, 4]，[2, 0]，[2, 1]，[2, 3]，[2, 4]，[3, 0]，[3, 1]，[3, 2]，[3, 4]，[4, 0]，[4, 1]，[4, 2] 和 [4, 3]。
```
**示例 3:**
```c
输入: M = 1, K = 1, nums = [28]
输出: 28
解释:
唯一的魔法序列是 [0]。
```
**提示:**
- `1 <= K <= M <= 30`
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 10^8`
---
### 方法 状态设计+多重集排列数+可行性剪枝
#### 题意
从 $[0, n - 1]$ 中选 $m$ 个下标 $I_0, I_1, \dots, I_{m-1}$ ，要求：$$\sum^{m-1}_{j=0} 2^{I_j}$$
的二进制中恰好有 $k$ 个 $1$ 。

定义 $$f(I) = \prod^{m-1}_{j=0} nums[I_j]$$
要求计算所有 $f(I)$ 的总和。
#### 公式简化变形
首先把式子简化，再确定思考方向。

假设在一组 $m$ 个下标中，选择了 $j$ 个重复下标 $i$ ，对答案的贡献是多少？

分两部分：
1. 对于所有包含 $j$ 个下标 $i$ 的 $I$ ，它们各自的贡献为 $nums[i]^j$ ，这个值再乘以其他下标的贡献；
2. 总共有 $m!$ 个不同的下标排列，其中有重复的，根据**可重集合排列数**，要除以 $j!$ 。

一个例子是 $[0, 1, 1]$ ，有 $3!=6$ 种排列，$[0, 1_1, 1_2], [0, 1_2, 1_1], [1_1, 0, 1_2], [1_1, 1_2, 0], [1_2, 0, 1_1], [1_2, 1_1, 0]$ 。不难看出，其中有 $3$ 个重复排列。

例如，$n = 2, m = 7$ ，选了 $3$ 个下标 $0$ 和 $4$ 个下标 $1$ ，那么：
1. 第一部分的贡献为 $nums[0]^3 \cdot nums[1]^4$ 。
2. 第二部分的贡献为 $\dfrac{7!}{3!4!}$ 。
这种选法（$3$ 个下标 $0$ 和 $4$ 个下标 $1$）如果合法（二进制恰好有 $k$ 个 $1$），那么对答案的贡献为：$$\dfrac{7!}{3!4!} \cdot nums[0]^3 \cdot nums[1]^4$$
将 $7!$ 提出来，变形得：$$7!\cdot \dfrac{nums[0]^3}{3!} \cdot \dfrac{nums[1]^4} {4!}$$
这样每一项都可独立计算了。

一般地，设我们分别选了 $c_0, c_1, c_2, \dots, c_{n-1}$ 个下标 $0, 1, 2, \dots, n - 1$ ，那么：
$$f(I) = \prod^{m-1}_{j=0} nums[I_j] = \prod^{n-1}_{i=0} nums[i]^{c_i}$$
枚举 $c_i$ ，把 $m!$ 提出来，答案为：
$$\sum_I f(I) = \sum \prod^{n-1}_{i=0} nums[i]^{c_i} = m! \sum_{c_0 + \dots + c_{n-1} = m} \prod^{n-1}_{i=0} \dfrac{nums[i]^{c_i} } {c_i !}$$
